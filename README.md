Entry for the [The Dumbest Thing Your Agent Did Today bounty on make.fun](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

`main.ts` (Node 22, standard library only, deterministic, no network) writes one
original line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set).

The line:

> My agent spent forty minutes confidently refactoring a file, then proudly announced it had deleted the bug — along with the feature, the tests, and my afternoon.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dumbest-out node main.ts
cat /tmp/dumbest-out/entry.txt
```
